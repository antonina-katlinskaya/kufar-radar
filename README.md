# Kufar ↔ Bir Radar — бесплатная версия

Радар контролирует один публичный профиль Kufar (`11093294`) и сравнивает его активные объявления с актуальным предложением Bir.by.

## Что проверяет

- цена в EUR;
- точная площадь;
- количество комнат;
- этаж;
- адрес/дом;
- существует ли соответствующий объект сейчас на Bir.by;
- повторные изменения после исправления;
- исчезновение объекта с Bir при активном объявлении Kufar.

## Нулевая стоимость

Эта версия рассчитана на:

- **публичный GitHub-репозиторий** — стандартные GitHub Actions для public repo бесплатны;
- **Cloudflare D1 Free** — только база истории, без R2 и без платных Browser Rendering;
- **Telegram Bot API** — бесплатно.

Скриншоты нарушений при необходимости отправляются сразу в Telegram и не требуют платного файлового хранилища.

## Частота

GitHub запускает проверку каждые 5 минут. Kufar проверяется каждый запуск. Bir по умолчанию обновляется раз в 15 минут и принудительно при команде `Проверить сейчас`.

## Секреты GitHub

Нужно будет добавить:

- `TELEGRAM_BOT_TOKEN`
- `CF_ACCOUNT_ID`
- `CF_D1_DATABASE_ID`
- `CF_D1_API_TOKEN`

Ни один секрет не должен попадать в код или чат.

## Первый запуск

1. Создать D1 базу в Cloudflare Free.
2. Выполнить `schema.sql` в D1 Console.
3. Добавить четыре секрета в GitHub Actions.
4. В Telegram написать боту `/start`.
5. Запустить workflow `Radar` вручную один раз.

Бот сам запомнит первый приватный Telegram chat как разрешённый чат.

## Важное ограничение

Kufar и Bir не публикуют стабильный официальный API-контракт для этих страниц. Сборщики используют браузер и перехват сетевых JSON-запросов с DOM-fallback. На первом запуске они сохраняют диагностические URL/типы ответов в D1 (`source_diagnostics`), чтобы можно было быстро оптимизировать прямой запрос без переписывания логики радара.
