# Схема без оплаты

## Почему не Replit / R2 / Cloudflare Browser Run

Постоянный Replit может требовать платный режим. R2 — usage-based продукт с checkout/billing-профилем. Browser Run на Free имеет только 10 минут браузера в день. Поэтому они **не используются** в обязательной схеме.

## Что используется

### 1. GitHub Actions — вычисления и Chromium

Проект должен быть **public**, тогда стандартные GitHub-hosted runners бесплатны и не расходуют платные минуты.

### 2. Cloudflare D1 Free — история

В D1 сохраняются только текстовые/числовые версии объявлений, сопоставления и события. Это очень мало данных.

### 3. Telegram — интерфейс и архив уведомлений

Бот получает команды через `getUpdates` во время каждого запуска GitHub Actions. Поэтому кнопка `Проверить сейчас` может сработать не мгновенно, а в пределах примерно 5 минут. Это цена полностью бесплатной схемы без постоянно работающего сервера.

## Что будет потом

Когда GitHub снова нормально подключится к ChatGPT, репозиторий можно создать и заполнить этим проектом. Cloudflare нужен только для создания D1 и API token с правами D1 Read/Write.
